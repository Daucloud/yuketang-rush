运行状态

记录播放时间、可见性和焦点，最多保留每项最近 180 条。平台是否计入进度仍需回查目录。

在学习日志或学习空间读取目录。默认只选未完成视频；作业在课程页面侧边批量分析，你自行作答。

批量粘贴单元链接

默认不抢焦点。课程窗口仍需可见；「重新平铺」会主动置前。

视频队列自动静音播放、回查完成状态并切换下一单元。作业页面有「答案建议」侧栏，点一次「收集全部并分析」，模型一次分析整份作业，不会选择选项或提交。

AI 模型设置

仅作业答案建议需要配置。扩展直接调用模型，无需 Node 或本地服务。请选择支持图片输入的 OpenAI 兼容接口。

密钥仅保存在 Chrome 本地，不同步；题干与选项图片发送至所配置的模型。保存时 Chrome 会询问该 API 站点的访问权限。连接测试和作业分析会产生模型 API 费用。

收集遇到核验、未保存答案提示或未适配题型会停止，不会发送不完整作业。

保持屏幕解锁，避免其他应用覆盖课程窗口。播放结束后以目录「已完成」为准。
