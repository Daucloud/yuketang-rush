# 雨课堂视频队列与作业答案建议

独立 Chrome MV3 扩展：静音视频队列，以及整份作业的模型答案建议。仅适配 `pro.yuketang.cn`，不支持其他雨课堂域名。当前版本 **0.3.5，实验版**。

视频队列和 AI 建议均直接在扩展内运行，无需 Node.js、`npm start` 或本地连接口令。AI 建议需要你自己的模型 API key，费用由所配置的提供商收取；请选择支持图片输入的 OpenAI 兼容接口。

## 当前行为

- 从「课程标签页」明确选择要读取的课程；读取学习日志、旧版「学习内容」内嵌目录或 AI 学习空间目录，默认仅选择未完成视频。重新读取会替换旧待选列表，切换课程或页面变化后须重新读取。运行状态显示的是已启动的队列，独立于新的待选列表。
- 1–4 个课程窗口，持续静音、真实播放，默认不抢焦点。视频播放结束后回查目录，平台明确显示已完成才进入下一项。
- 作业独立于视频队列：右侧显示「作业答案建议」，由用户自行选择与提交。自动选择和提交的旧消息接口已禁用，旧配置中的 `autoQA` 也不会恢复自动提交。
- 点一次「收集全部并分析」，先读取整份题面，再通过一次模型请求分析全部题目；模型不再逐题调用。结果按题号显示，切题只更新侧栏高亮。
- 收集通过正常题号导航完成，不读取隐藏答案或直接调用平台作答接口。页面只渲染当前题，所以收集题面仍需要依次切换题号。收齐后回到原题。
- 已提交的题目也可收集用于复习。当前题存在未提交选择、安全核验或未保存答案提示时，停止收集；不会清除选择、确认弹窗或提交。
- 题干及选项按页面实际字体渲染为图片，避免字体混淆造成乱码。扩展直接把图片发送给配置的视觉模型，不需要 OCR。
- 建议包含题干明文、选项、推荐答案与依据。不确定或口径冲突的题目显示「需核实」，不推荐猜测。
- 相同题面使用本地缓存；缓存仅保留最近 10 份作业的文字建议、时间与指纹，不保存图片。重新打开时会标注上次分析时间；题面变化后应重新收集。

## 更新已有安装

1. 在 Chrome 或 Chrome for Testing 的扩展管理页，重新加载「雨课堂 · 平铺学习助手」。
2. 刷新课程页面，让新的侧栏和视频逻辑生效。不要只刷新旧控制页。
3. 在控制页的「AI 模型设置」填写 API 基地址、模型名称和自己的 API key。保存时允许 Chrome 访问该 API 站点，然后点击「测试连接与图片输入」。
4. 在「课程标签页」中选择目标课程，读取目录、选择视频，再开始队列。作业请单独打开，使用右侧「收集全部并分析」。

源码更新不会自动替换已经运行的内容脚本。新侧栏出现、旧自动答题开关消失后，才表明浏览器加载了新版。

## 首次安装

1. 从 [Releases](https://github.com/Daucloud/yuketang-rush/releases/tag/v0.3.5) 下载 `yuketang-extension-0.3.5.zip`，解压到固定文件夹。
2. 在你的 Chrome 打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择解压后的 `extension` 文件夹。
4. 登录课程并刷新页面，点击扩展图标打开控制页，读取目录、选择视频并启动队列。
5. 如需作业建议，按下节在扩展内配置模型，然后打开作业侧栏。

普通 Chrome 即可使用，无需安装 Chrome for Testing。源码包也包含 `extension` 文件夹；可直接加载。`scripts/open-chrome.sh` 仅是 macOS 开发辅助脚本，不是安装步骤。

从目录打开单元时，助手拦截受管课程弹窗并在原标签页导航。若无法完成握手，队列停止，不会不断打开新窗口。默认不置前；「重新平铺」仍会主动调整并置前窗口。

## AI 模型设置

在控制页填写并保存三个字段：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| API 基地址 | `https://api.deepseek.com` | 不含 `/chat/completions`；其他提供商需要 `/v1` 时应保留 |
| 模型名称 | `deepseek-flash` | 必须支持图片输入和 OpenAI 兼容的聊天接口 |
| API key | 你自己的模型密钥 | 不提供共用密钥 |

保存时 Chrome 会请求该 API 站点的访问权限。首次配置后点击「测试连接与图片输入」，测试会发送一张空白示例图片并产生少量 API 费用。保存设置不会自动调用模型。

密钥、课程队列及答案缓存在本机使用 AES-256-GCM 加密保存，不使用浏览器同步；内容脚本不能直接读取该存储。控制页不回显已保存的密钥，留空可保留同一 API 站点的密钥，更换站点需要重新填写。点击「删除已保存的密钥与设置」可删除配置与答案缓存。更改模型设置会取消进行中的分析并清除旧缓存。

每份作业使用一次模型请求，支持 1–100 题、题面数据最多 32 MB。最多并行两个分析请求；模型调用最长 120 秒，整批分析最长 150 秒。扩展接收流式响应，校验全部题号、选项与题面转写后才显示答案。题号缺失、重复或未知选项会使整批失败。

从旧版升级时无需运行 `npm start`，也无需填写 `BRIDGE_TOKEN`。旧 `.env` 中的模型配置不会自动导入 Chrome，请在设置中填写一次。

源码仍保留旧版 `server.mjs` 与 macOS OCR 模块，供开发测试和兼容性研究；0.3.5 扩展不连接它们。

## 暂停、缓存与边界

- 「暂停全部 / 继续队列」控制视频播放；作业建议有独立的「取消」按钮，不依赖视频队列是否暂停。
- 「清除建议」取消进行中的分析并删除当前作业建议，不修改平台上的答案。
- 题面中的插图、填空、简答和无法识别的题型目前会使整份收集停止。纯文字题渲染成图片用于读取字体，不等同于支持所有图片题。
- 切题时遇到核验就停止；批量分析不保证避免平台核验。
- 若浏览器阻止自动播放、锁屏、媒体加载失败、后台冻结或平台不计入时长，需要处理后重试。不会伪造时间、可见性、焦点或完成记录。
- 只有带目录定位信息的任务能自动回查并切到下一视频；单独粘贴的视频链接结束后需要手动确认。
- 不读取 Cookie、不写入平台学习时长或成绩接口。模型建议可能错误，应核对课程资料后作答。

## 开发验证

```sh
npm ci
npm run check
npm test
```

本地测试覆盖视频队列、静音与窗口焦点、整批单次请求、题号与选项映射、缓存、取消、核验停止和不选择不提交。界面示例可运行：

```sh
node scripts/preview-advice.mjs
```

预览地址：`http://127.0.0.1:8767/v2/web/iframe-exercise/1/1`。仅使用示例答案，不连接课程或模型。当前通过 85 项本地自动化测试、模拟界面验证及真实模型的图片连接测试和示例题直接调用。新版自动视频队列尚未完成真实课程端到端验证，不能保证所有页面与后台播放环境均可运行。详见 [更新记录](CHANGELOG.md)。
