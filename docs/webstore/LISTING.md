## 商品说明（可直接粘贴）

为 pro.yuketang.cn 提供课程学习工作区：组织静音视频播放队列，并在客观题页面旁显示 AI 学习建议。独立开源扩展，与雨课堂及课程提供方无官方隶属关系。

主要功能：
- 明确选择课程标签页，重新读取时替换历史待选列表。
- 将所选视频安排在 1–4 个课程窗口中；默认静音、不抢焦点，可统一暂停、继续与重新平铺。
- 播放结束后回查课程目录，平台显示完成后再安排下一单元；显示排队、运行、完成和需处理状态。
- 一次收集整份选择题，通过一次模型请求生成题干转写、建议答案与简短依据；切换题号时，侧栏高亮并滚动到对应建议。
- 用户自行选择答案与提交。遇到安全核验、未保存选择或未支持题型时停止收集。
- 扩展直接调用用户配置的视觉模型，无需 Node.js 或本地服务。连接测试立即展示进度与结果。

AI 建议需要用户自己的 API key，模型费用由所选提供商收取。题干与选项图片在用户主动分析时直接发送到该 API。密钥、课程队列及答案缓存使用本机加密存储，不通过 Chrome 同步，也不发送给开发者服务器。

仅支持 pro.yuketang.cn。填空、简答与含插图题暂不支持。建议可能出错，请结合课程资料核对。视频是否计入进度由平台决定；扩展不伪造时长、焦点或完成记录，不绕过安全核验。当前是实验版，自动视频队列的真实课程完整流程仍待验证。

源码、使用说明和隐私政策可从项目网站查看。

为雨课堂课程提供用户可控的学习工作区：组织视频播放，并辅助理解页面中的客观题。所有权限与数据处理均用于这些可见的课程学习功能。

## 权限用途（按面板字段粘贴）

| 权限 | 必要用途 |
| --- | --- |
| storage | 加密保存所选课程、队列状态、播放诊断、模型配置及最近十份作业建议；内容脚本不能直接读取 |
| alarms | 定期检查已启动队列是否仍收到页面状态，不在用户未启动队列时播放课程 |
| system.display | 读取显示器工作区，用于用户选择显示器及排列 1–4 个课程窗口，不获取精确地理位置 |
| power | 已启动的视频队列期间保持显示器唤醒，暂停或无待运行任务时释放，不修改系统永久设置 |
| https://pro.yuketang.cn/* | 读取所选课程目录、播放状态和可见题面，并插入学习建议侧栏；不读取其他课程域名或 Cookie |
| 可选 https://*/* | 用户可填写任意 OpenAI 兼容的 HTTPS 视觉模型 API，因此需声明可选 HTTPS 站点。仅在用户保存设置时请求所填 API 的单一 origin 权限；不会自动请求全部 HTTPS 网站权限 |
| 可选 http://localhost/*、http://127.0.0.1/*、http://[::1]/* | 允许用户主动配置本机模型 API，仅限回环地址；远程模型地址必须使用 HTTPS |

远程代码：不使用。扩展的 JavaScript 全部打包在 ZIP 中；模型响应作为文字建议渲染，不下载或执行模型返回的代码。

## 隐私实践披露

不得选择「不处理用户数据」。即使仅在本地保存，也应披露所处理的数据。

根据当前代码，面板中对应的数据类型包括：
- Authentication information：用户配置的模型 API key，本机加密保存并仅用于所选 API 的认证。
- Website content：题干、选项图片、课程目录与模型建议。
- Web history：仅用户操作的课程单元网址与队列网址，不读取完整浏览历史。
- User activity：播放时间、倍速、暂停状态、页面可见性及焦点等本地诊断，不追踪其他页面行为。

按面板的实际名称和解释核对上述分类。可如实声明：不出售用户数据、不用于与单一用途无关的目的、不用于信用评估或贷款。隐私政策已说明第三方模型传输、加密方式、本地留存与删除方式。

## 审核测试说明

1. 普通 Chrome 120 或以上版本；使用自己有权访问的 pro.yuketang.cn 课程。
2. 点击扩展图标，读取课程目录，选择视频后开始队列。观察静音、窗口焦点、暂停与继续，以及平台目录完成标记。
3. 打开选择题作业；使用有权使用的视觉模型 API，在扩展设置中同意并保存配置。连接测试会产生少量 API 费用。
4. 收集整份题目；确认仅一次模型分析，切题时对应建议滚到侧栏可见区域，且扩展不会选择或提交答案。
5. 出现安全核验或未保存选择时，应停止收集。

开发预览可运行 `node scripts/preview-store.mjs` 与 `node scripts/preview-advice.mjs`，仅用示例数据展示界面，不能代替真实课程验证。不得在公开仓库或商店文案中放课程账户、API key 或个人截图。如审核面板要求测试凭据，需由发布者提供经授权的测试账户。
